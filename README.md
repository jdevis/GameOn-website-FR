# GameOn

Project 04 [Openclassrooms React application developer training course](https://openclassrooms.com/fr/paths/2288-developpeur-dapplication-react)
Javascript validation of a registration form for a website specializing in video game conferences and contests

## 🚀 Features

Add the missing JavaScript code to make the form fully functional. Templates provided on [figma](https://www.figma.com/design/B7NKBDvSI18uoMLJgpnh48/UI-Design-GameOn-FR?node-id=106-630)
And publish it on [Github Pages](https://jdevis.github.io/gameOn/)

-   Working on a forked GitHub repo
-   Using separate files for HTML, CSS and JavaScript;
-   Always commenting your code (describing each function and class, as well as parts of the code that require more detail);
-   Manually testing functionality, form input and responsive display.

[See Issues](https://github.com/OpenClassrooms-Student-Center/GameOn-website-FR/issues)
